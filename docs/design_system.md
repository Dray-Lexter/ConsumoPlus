# Sistema visual: Hogar claro

ConsumoPlus usa Material 3 como unico sistema de componentes. La identidad es
domestica y confiable, no un dashboard empresarial.

- Agua: azul `AppColors.water`, contenedores suaves y radios amplios.
- Electricidad: amarillo/naranja y una forma mas dinamica.
- Fondo calido claro, tinta oscura y superficies blancas.
- Espacios, radios, duraciones, tipografia y colores viven en `app/theme/`.
- Controles tactiles conservan al menos 48 dp y las pantallas son desplazables.
- El grafico de consumo incluye una descripcion semantica y una lista textual.
- Importe del mes, deuda anterior y total se presentan con etiquetas distintas.
- Cargas, vacio, error, exito y datos locales tienen estados honestos.

La aplicacion de `design-taste-frontend` se limita a criterios compatibles con
Flutter movil: consistencia, jerarquia, densidad, movimiento sobrio,
accesibilidad y ausencia de controles ficticios.
